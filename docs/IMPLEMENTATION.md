## 数学对应

| 论文 | 实现 |
|---|---|
| (1) `Y = Φ([g ⊙ S,T,I])` | `ShallowGateConcat` 后接 `C3k2`；额外 S 无未加权旁路 |
| (2) `u(A) = L(Poff;A) - L(Pon;A)` | `FixedBundleLoss.evaluate` 只使用传入目标包，不调用 assigner |
| (3) `u_sym = (u(Aon)+u(Aoff))/2` | `contrast`；Aon/Aoff 都从 detached 预测生成 |
| (4) `s=median_train(abs(u)); z=u/s` | 全部训练标签统一缩放；偶数样本取中间两项均值；零尺度报错 |
| (5) `mean SmoothL1(z_hat,z)` | beta=1；保留近零标签；不混入检测损失 |
| (6) `g=exp(min(0,z_hat)/tau)` | tau=1；正预测统一 g=1，排序应使用 z_hat |

分类、CIoU 框回归和 DFL 权重分别为 .5、7.5、1.5，涵盖所有 P3/P4/P5 位置。TAL 为 top-k=10、alpha=.5、beta=6。每个目标包保留前景掩码、GT ID、软类别目标、框、权重及逐图分母。BboxLoss 从固定软目标导出相同的权重。一个参考包内两端共用分母；两参考包可使用不同分母。无 GT 的图像保留背景分类项，分母为 1。

探针冻结所有参数、BN 和随机层；回归阶段只训练 3 个投影和 MLP。额外分支关闭不阻止普通 backbone 内的浅层传播。软门控不跳过后续卷积，不宣称节省 FLOPs。

## 工程重建选择（论文未完整定义）

1. **连接点和对齐**：锁定 YOLO11n v8.3.40；S 来自第 2 层（P2、64 通道），用 area average 下采样到第 14 层 T（128 通道）的 P3 网格；I 来自第 4 层（128 通道）。替换第 15 层拼接和第 16 层 C3k2 输入宽度，输出 64 通道。论文只给出 S/T/I 尺度和通道，没有提供原始 YAML 或完整 Φ，因此这是明确的重建方案，不能保证参数量/计算量等于论文表格。
2. **融合块**：使用 C3k2(320,64,n=1,e=.5,c3k=False)。不是对早期所有自定义模块的猜测性复写。
3. **描述投影**：三个独立带偏置线性层将区域通道均值映射到各 16 维，拼接后 Linear(48,24)–SiLU–Linear(24,1)。边界不完整区域按有效元素求均值，门控按块重复并裁剪。
4. **掩码解释**：每图选择模式；区域二值模式随机选 20% 区域置零，未选区域保持 1；连续模式随机选 20% 区域替换为 U(.1,1)，其余保持 1。论文未另给二值模式内部第二次 Bernoulli 采样规则。
5. **采样**：每次 draw 内不放回抽 4 个区域，两次 draw 之间允许重复。默认 640/8 得到 10×10 区域；5,985×2×4=47,880，70,000×2×4=560,000。
6. **M7**：同一冻结探针和路由器，动态目标分配，确定性预处理；按图片 minibatch 平均逐图损失。论文未完整给出 M7 的增强和采样细节，不能声称逐步一致。
7. **优化器细节**：沿用锁定 Ultralytics 的 SGD 参数分组、warm-up 和 nominal batch size=64 机制（含梯度累积、权重衰减缩放）。论文未披露这些内部选择。Router 使用 AdamW 默认 betas=(.9,.999)，余弦调度器 eta_min=1e-5，调度在每轮后推进。
8. **预处理**：标签阶段使用固定方形 letterbox，与训练增强隔离；评估也指定方形输入、FP32、无 TTA、class-aware NMS .7、conf .001、max_det=300。

实际构建得到 KITTI 8 类模型 **2,601,865** 个参数，BDD100K 10 类模型 **2,602,255** 个参数，均包含路由器。这与论文的 2.69 M 不同，说明未公开的原始网络细节仍需核对；本实现没有通过随意增加通道来凑参数量。640 输入下已检查 S/T/I 分别为 64/128/128×80×80，区域为 10×10，三个检测尺度合计 8,400 个位置。

## 运行记录

每次训练使用新的输出目录。最终探针导出 `probe_final.pt`，最终路由器导出 `router_final.pt`，均为普通 tensor/config checkpoint。上游 `weights/best.pt` 不用于此方法；论文选择的是最后一轮。若中断导致标签目录没有 `manifest.json`，该缓存不完整，不能送入回归训练。开始新任务时指定新目录。

标签 manifest 记录探针/配置/分片哈希和完整图片清单，但没有逐个哈希图片及标注文件。请在首次运行前冻结数据快照；同一路径下内容被替换不会由路径重叠检查发现。不要在标签生成后修改数据再将结果视为同一实验。

BDD100K 的全部描述缓存约 0.7 GB（FP32，560,000×320），当前回归入口将全部分片读入内存，建议预留数 GB CPU RAM。标签生成按单图串行，速度与论文实现未必一致。代码提供缓存复用，不假设训练耗时与论文相同。
